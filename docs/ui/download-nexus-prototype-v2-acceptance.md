## 0. 换算基准（证据前提）

面板底不是纯色，是「壁纸 + 0.90/0.94 玻璃」合成值，所以所有对比度都按合成后计算：

| 表面 | 合成值（深） | 合成值（浅） |
| --- | --- | --- |
| 壁纸 | `#0a1220`（热点 `#12335e`） | `#eef3fb` |
| 主面板 `.panel` | `#142037`（热点后 `#15243d`） | `#fefeff` |
| 引擎卡 `.engine` | `#10192c` | ≈`#fefeff`（1.05:1） |
| 输入框 `.input` | `#0e1727` | `#f7f9fd` |
| 描边 `--line` | `#253552`（1.32:1） | `#e0e2e7`（1.29:1） |

复算：`L=(0.2126R+0.7152G+0.0722B)`（sRGB 线性化后），`ratio=(L1+0.05)/(L2+0.05)`。

### 维度 1 · 壁纸干扰 / 主面板不透明度 / 文字对比度 — **FAIL**

| 断言 | 实测（合成后对比度 / 规格） | 判定 |
| --- | --- | --- |
| 正文 13px `--text` | 深 14.08:1 / 浅 15.60:1 | PASS |
| 说明 12px `--muted` | 深 7.92:1（壁纸热点后 7.57）/ 浅 6.10:1 | PASS |
| 极弱 11px `--faint` | 深 4.90:1（热点后 4.68 / 引擎卡 5.28）；**浅 4.18:1** | **FAIL（浅色）** |
| 主面板不透明度 | `--glass-1` = 0.90→0.94（`prototype:28`），叠加 `backdrop-filter: blur(20px)`（`prototype:226`） | **FAIL**：主卡不是不透明层，6–10% 壁纸穿透；基线 R1.2 明确「卡片是不透明 layer-2，半透明只属于浮层」 |
| 字号分档 | 11px 承担了「说明」职责：`.hint`(:279)、`.engine-note`(:369)、`.engine-detail`(:380)、`.tag`(:156)、`.field-err`(:291)、`.at`(:385) | **FAIL**：13/12/11 三档在实现里塌成 13/12/11→实际是 13/12/11/11，说明档被压到极弱档 |

**证据定位**
- `prototype:35` 注释自称「12px 说明文字对 #0d1524 ≈ 7.2:1」——只算了玻璃底部色，没算壁纸穿透与顶部色，实测 7.92 达标属侥幸，不属于设计保证。
- `prototype:30` `.hd` = `rgba(9,15,26,.82)` + `:123` `backdrop-filter: blur(14px)`；`prototype:122` 背景是 `linear-gradient(180deg, var(--glass-head) 72%, transparent)` → **顶栏底部 28% 完全透明，滚动时正文文字从保存按钮下方穿过**。
- `prototype:194-195` `.tabs` = `color-mix(... 78%)` + `blur(12px)` → 22% 滚动内容透视，粘性条对比度随内容变化。
- `prototype:31` 描边 `rgba(126,165,224,.16)` → 1.32:1，`--line-soft` `.10` → 1.18:1，都低于既有基线 `border-l4`(1.45) 与 3:1 图形基线。

**必须修**
1. 主面板改不透明：`--glass-1` → 实色 `--bg-1` 派生（深 `#0d1524`/浅 `#ffffff`），`backdrop-filter` 只留给 `.modal` / `.toast` / `#tools`。
2. 顶栏与 tab 条改实色底（`--bg-0` 或 `--bg-1`），删掉「72% 渐隐到 transparent」，否则粘性区永远透字。
3. 浅色 `--faint` 从 `#6f7c93`(4.18) 加深到 `#5c6880` 以上（目标 ≥4.5）；`--idle`(4.32, 12px 文字) 同理。
4. 说明类文案统一 12px：`.hint` / `.engine-note` / `.engine-detail` / `.tag` 提到 `--fs-sm`；11px 只留 `.section-label` 与时间戳。

### 维度 2 · 卡片三层层次（主面板 / 输入框 / 引擎卡） — **FAIL**

| 相邻层 | 深色对比 | 结论 |
| --- | --- | --- |
| 引擎卡 vs 主面板 | 1.08:1 | 几乎同色 |
| 输入框 vs 主面板 | 1.10:1 | 几乎同色 |
| 输入框 vs 引擎卡 | **1.02:1** | 无法区分 |
| 描边 `--line` vs 面板 | 1.32:1 | 只能靠描边勉强分，低于 3:1 |

**证据定位**
- `prototype:223-229`：三层全部靠同一个 `--line` 描边 + 同一族玻璃底，层级差全在 1.02–1.10:1。
- `prototype:351` 引擎卡 `color-mix(bg-0 30%)` 与 `:283` 输入框 `color-mix(bg-0 42%)` 用不同 alpha 表达「同一嵌套深度」，导致两者互相压平。
- 深色下 `--shadow: 0 16px 40px rgba(0,0,0,.34)`（`:49`）落在近黑底上等于不可见 → **层级只剩投影的空壳**，正是基线 R10#19「深色用投影表达层级 → 层级塌陷」。
- 浅色 `input vs panel = 1.05:1`，等于输入框与卡片同色，只有 1.29:1 的边框告示它存在。

**必须修**
1. 建立三档明度阶梯而不是三档 alpha：面板 `layer-2`，输入框 `layer-1`（**比面板更暗/更亮一档，不是 42% 黑**），引擎卡 `layer-3` + 描边。
2. 描边统一 `--line-strong`(.28) 用于面板，`--line`(.16) 只做分隔线；禁用 1.1x 级色差当层级。
3. 深色层级改用明度差 + 1px 高光内描边（`--inset` 已有），删掉承担层级职责的投影。

## 4. 原型 vs 现有实现：别照原型倒退
